# Afya Showroom project — start here

1. Open this folder in Claude Code.
2. Paste the message in AFYA_SHOWROOM_BRIEF.md, Part A2, as your first message.

What is already here (so Claude Code does not need the artifact link to start):
- AFYA_SHOWROOM_BRIEF.md — the full guideline.
- showroom-original/ — the showroom's complete code as published on 5 Nov 2026:
  index.html, all 15 section scripts (sections/*.js incl. sw-dict.js, range*.js, fp.js),
  and img/boxdoor.webp. Images and videos (img/, media/ — ~490 files) are NOT in this
  folder; they stay on the published artifact and remain attached when the page is
  published back with its URL. Pull any single one with the Artifact tool
  (action "read", path "img/<name>" or "media/<name>") when a section needs it.
- assets/boxes/ — the locked box reference and the three approved Weavy renders.
- preview-box-opens.html — the working Box Opens hero preview (motion and layout only;
  its item text is placeholder).
